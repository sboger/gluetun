Gluetun Web UI

a thin browser front-end for the gluetun control server API. Requests are proxied to /v1/... with the configured API key. GET buttons fetch state; PUT/forms change it where the API allows.

Version

GET /v1/version 
click GET to load

VPN status

GET /v1/vpn/status
PUT /v1/vpn/status {"status":"..."} 
click GET to load

Public IP

GET /v1/publicip/ip 
click GET to load

Port forwarding

GET /v1/portforward 
click GET to load

BitTorrent torrents

GET /v1/bittorrent/torrents
POST /v1/bittorrent/torrents {"magnet":"..."}
DELETE /v1/bittorrent/torrents {"info_hash":"..."} 
click GET list to load
